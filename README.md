# Fathima Fida — Portfolio

A cleaned and professionally organized version of the existing single-page portfolio.

## Project structure

```text
Fathima-Fida-Portfolio/
├── index.html
├── css/
│   ├── reset.css
│   ├── variables.css
│   ├── global.css
│   ├── components.css
│   └── responsive.css
├── assets/
│   └── images/
│       └── officephoto.png
└── README.md
```

## Notes

- The existing visual design, colors, typography, content, animations, navigation anchors, image and responsive behavior have been retained.
- CSS that was embedded in the original HTML has been separated into maintainable files.
- Design values are centralized in `css/variables.css`.
- Reusable button styles and animations are kept in `css/components.css`.
- Responsive rules are isolated in `css/responsive.css`.
- The supplied professional photo is stored under `assets/images/`.
- No JavaScript folder was added because the existing portfolio does not contain JavaScript functionality; navigation and animations are handled by HTML/CSS. This avoids unnecessary empty files.
- Open `index.html` directly in VS Code/Live Server to run the portfolio.
